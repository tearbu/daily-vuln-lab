# Daily Vuln Lab

A daily, hands-on study project: each morning I review newly disclosed vulnerabilities surfaced on Hacker News, pick the most significant one, and build a small, focused lab on it — a detection rule, a checker script, or a configuration analysis — published here with a written analysis.

Every artifact is built from public sources, uses fictional sample data only, and is run locally before publishing. No exploit code is included.
